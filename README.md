# Power BI - Pivot and DAX

## 📌 Project Overview

This project demonstrates business intelligence and data analysis using Microsoft Power BI. It focuses on transforming raw data into meaningful insights through data modeling, Pivot analysis, DAX calculations, and interactive dashboards. The dashboard enables users to monitor key business metrics and make informed decisions using visual analytics.

---

## 🎯 Project Objective

- Analyze business data using Power BI.
- Build an interactive dashboard with meaningful visualizations.
- Perform data modeling and create relationships between tables.
- Use DAX measures and calculated columns for advanced analysis.
- Present business insights through dynamic reports.

---
